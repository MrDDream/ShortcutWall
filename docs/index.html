Features

Everything a start page needs, nothing it doesn't

No database, no account to create for visitors: a JSON file, your logos, and a fast page.

Shortcut wall

Large cards with logo, name and description. One click opens the site.

Instant search & sort

Press / to search names, descriptions and domains; sort A–Z or by most recent.

Automatic logos

Finds the best icon a site offers, stores it in the app and shrinks it to 256 px. No broken images.

Internal sites too

Your router, NAS or Proxmox on the local network or a VPN, self-signed certificates included.

Admin in dialogs

Add, edit and delete without leaving the list. A deletion can be undone for 15 s.

Export / import

One JSON file with every shortcut and its logos, to back up or move an install.

Light, dark, mobile

Follows the system theme, in French or English, on any screen size.

Secure by default

CSRF tokens, strict CSP, login rate limiting, SSRF guard, non-root image. No default password.

Administration

Add a site in a few seconds

Type the address, click “Fetch favicon”, done. Everything happens in a dialog, without losing your place.

  • The best icon of the site, checked and resized
  • Or upload your own image, PNG, JPEG or WebP
  • Errors show in the dialog, your input is kept

Installation

Up and running in three steps

A prebuilt image for linux/amd64 and linux/arm64 (Raspberry Pi). All you need is Docker with Compose.

Create a folder with this docker-compose.yml

docker-compose.yml 
services:
  shortcutwall:
    image: ghcr.io/mrddream/shortcutwall:latest
    container_name: ShortcutWall
    ports:
      - "${PORT:-3050}:${PORT:-3050}"
    # ADMIN_USER, ADMIN_PASS, SESSION_SECRET… come from .env (see .env.example):
    # the app refuses to start in production without real values.
    env_file:
      - path: .env
        required: false
    environment:
      NODE_ENV: production
      PORT: ${PORT:-3050}
      HOST: ${HOST:-0.0.0.0}
    volumes:
      - ./data:/app/data
      - ./public/uploads:/app/public/uploads
    restart: unless-stopped

Create the data folders and the .env file

The container runs as uid 1000: create the folders yourself, then pick your admin password.

bash 
mkdir -p data public/uploads
printf 'ADMIN_USER=admin\nADMIN_PASS=%s\nSESSION_SECRET=%s\n' 'choose-a-strong-password' "$(openssl rand -hex 32)" > .env

Start

bash 
docker compose up -d

The wall is at http://localhost:3050, the admin area at /admin. To update: docker compose pull && docker compose up -d

Configuration, security and troubleshooting are in the README.
